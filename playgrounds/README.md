# VSlices Playgrounds

**Status:** experimental specifications and possible realizations, not canonical semantics or approved operational procedures.

Playgrounds explore whether a bounded VSlices idea can be inspected, visualized, challenged or eventually automated. A playground may consume Method, Design, mechanisms, evidence, Tooling or LLM capabilities **without acquiring authority to redefine them**.

## Candidates

- [Value Orientations — evidence-driven triangle](value-orientations/README.md): visualize how interpreted work forces and evolving evidence might influence the emphasis used by Method to recommend a Design modality for **one standalone iteration**.

## Boundaries

- Keep simulation, evidence interpretation, recommendation and actual authorized decision distinct.
- Do not invent data or convert an attractive visualization into a validated decision rule.
- A prototype implementation is optional; this folder initially contains a **specification**, not a running playground.
- Composite or nested iteration orchestration is explicitly outside the first Value Orientations playground.
