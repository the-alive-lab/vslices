# Work Modeling — denominación histórica

**Estado:** denominación anterior; sustituida por **[Domain Modeling](domain-modeling.md)** el 2026-11-10.

Esta ruta se conserva para referencias previas. La definición vigente, sus ámbitos `Work Semantics` y `System Realizations`, sus relaciones con Spaces, Features y Capabilities, preguntas abiertas y trayectoria pertenecen exclusivamente a [Domain Modeling](domain-modeling.md).

**Evolución:** `Action Flow → Work Modeling → Domain Modeling`. `Work Modeling` sustituyó inicialmente a `Action Flow` porque modelar trabajo no exige un flujo de acciones; posteriormente se reconoció que la sistematización **descubre y expresa** conceptos y funcionalidades del dominio, excediendo el modelado del trabajo por sí solo.

La definición anterior permanece recuperable en el historial Git de este archivo. No actualizarla como una segunda fuente conceptual.
