# System Process — proceso de sistema

**Estado:** nivel candidato de System Realizations.

Un **System Process** es la **coordinación de acciones de sistema** que permite realizar una intención reconocible, como atender «Crear solicitud de pago DS 49» en la frontera operacional de un producto.

Puede coordinar múltiples [System Actions](system-action.md), que a su vez pueden requerir [System Steps](system-step.md). Puede corresponder a la sistematización de un [Work Flow](work-flow.md), **sin implicar identidad ni correspondencia uno a uno**.

No equivale automáticamente a **una instancia persistida de proceso** gestionada por un orquestador. Las responsabilidades relativas a sus estados, transiciones, reglas e historia siguen abiertas.

Véase [System Realizations](system-realizations.md).
