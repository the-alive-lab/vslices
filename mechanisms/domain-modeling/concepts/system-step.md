# System Step — paso de sistema

**Estado:** nivel candidato de System Realizations.

Un **System Step** es una **operación concreta de realización** que puede formar parte de una [System Action](system-action.md).

**Ejemplos candidatos:** validar una solicitud de pago o persistir cambios.

Su presencia no fija tecnología, transacción, servicio propietario ni contratos ejecutables; esas decisiones requieren evidencia y autoridad del diseño pertinente.

Véase [System Realizations](system-realizations.md).
