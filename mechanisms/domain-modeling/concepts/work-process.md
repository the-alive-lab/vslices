# Work Process — proceso de trabajo

**Estado:** nivel candidato de Work Semantics.

Un **Work Process** es una **parte reconocible de una [Work Chain](work-chain.md)** que coordina [Work Flows](work-flow.md) y sus relaciones para contribuir a un resultado del trabajo.

Debe representar las acciones y relaciones **pertinentes al proceso**, sin reproducir automáticamente todas las decisiones y operaciones internas de cada Work Flow. Una condición entre flujos puede expresarse como relación; su representación gráfica no requiere una forma universal.

No es sinónimo de estado de software, endpoint, pantalla o instancia persistida administrada por un orquestador.

**Ejemplo:** gestión de solicitud de soporte.
