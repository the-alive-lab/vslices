# System Action — acción de sistema

**Estado:** nombre y nivel **candidatos**; se consideró anteriormente `System Section`.

Una **System Action** es una **acción funcional semánticamente identificable** que puede participar en la coordinación de un [System Process](system-process.md).

**Ejemplos candidatos:** crear solicitud de pago, notificar solicitante, notificar revisor o registrar una actuación de auditoría.

Puede incluir [System Steps](system-step.md) concretos. Su identidad semántica no impone un endpoint, Feature, servicio, clase ni repositorio separado; tampoco obliga a una frontera transaccional particular.

Véase [System Realizations](system-realizations.md).
