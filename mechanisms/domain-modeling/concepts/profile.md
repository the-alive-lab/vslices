# Perfil — perfil organizacional

**Estado:** definición conceptual candidata.

Un **perfil** expresa una **función o responsabilidad organizacional contextual** que un [actor](actor.md) puede desempeñar al participar en el trabajo, especialmente en un [Work Flow](work-flow.md).

No equivale por sí solo a cargo contractual, categoría permanente de persona, identidad, cuenta, permiso o grupo técnico. Un mismo participante puede desempeñar perfiles diferentes; la compatibilidad entre perfiles y tipos de actor depende del contexto estudiado.

La relación entre perfil, acción ejecutada, otros participantes y responsabilidad debe **justificarse con evidencia**. Cuando no se conoce el perfil ejecutor, se conserva como pendiente; no se inventa para completar un diagrama.

Véase [Paso 3: identificar perfiles](../usage-guide/03-identificar-perfiles.md).
