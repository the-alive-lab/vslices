# Docs Standard — legacy modeling assessment

**Owner:** VSlices Docs Standard. **Status:** historical boundary; not normative artifact semantics.

[Historical public modeling](https://github.com/vslices/docs/blob/main/es/products/docs-standard/how-to-use/modeling.md) introduced a progression: L0 Note, L1 Minimal Document, L2 Expanded Document, L3 Reference Document. It also discussed states, metadata, relations, granularity and document identities using Process, Use Case and Capability examples.

## Retain the underlying intentions

- Knowledge should become more explicit when relevant evidence, complexity or risk demands it.
- Preserve enough identity, references and state to retrieve and evaluate knowledge.
- Avoid making every observation a formal Document.
- Divide or compose when this improves clarity, ownership or continuity, not from template convenience.
- Historic and superseded material can remain accessible without pretending to be current truth.

## Do not promote as present definitions

- L0–L3 as maturity levels or a required evolution of artifact instances.
- Fixed Process, Use Case or Capability Document types from the older taxonomy.
- Universal conversion of Support Notes into Documents.
- Sample front matter as the current normative YAML language.
- The sample supports/refines/depends-on/validates/challenges/supersedes list as a closed relations enum.
- Historical continuity-path classifications or the five public perspectives as exhaustive vocabulary.

The current normative type definitions live in [vslices/docs-standard](https://github.com/vslices/docs-standard). Documentary descriptions in [public taxonomy](https://github.com/vslices/docs/tree/main/es/products/docs-standard/taxonomy) and [public paths](https://github.com/vslices/docs/tree/main/es/products/docs-standard/continuity-paths) are historical, not alternative normative sources.

This migration does not modify the original publications. Other product concepts beyond their legacy artifact definitions can remain relevant and should be reviewed independently.
