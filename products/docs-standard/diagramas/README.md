# Diagramas — VSlices Docs Standard

Esta superficie reúne **definiciones de representación documental**. Describe cómo expresar y leer una proyección del conocimiento, sin redefinir los conceptos modelados ni imponer el uso de un diagrama para alcanzar claridad sobre el dominio.

## Diagramas definidos

- [Work Coordination Diagram](work-coordination-diagram.md) — representación de acciones semánticas de trabajo, sus perfiles, posiciones de orden lógico y relaciones conocidas.

## Alcance y autoridad

**Docs Standard** conserva la semántica de las representaciones y sus convenciones de lectura. Los conceptos de [Domain Modeling](../../../mechanisms/domain-modeling/README.md) —como Work Process, Work Flow y perfil— mantienen su autoridad en ese mecanismo.

Un diagrama es una **proyección examinable**, no el trabajo mismo. Su adopción, formato de archivo y herramienta de renderizado no son requisitos para comprender el dominio.
