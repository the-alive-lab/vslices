# VSlices Docs Standard — principles

**Owner:** VSlices Docs Standard. **Status:** bounded canonical migration.

**Document to preserve useful knowledge, not to complete a list.**

Docs Standard protects continuity among domain understanding, decisions, realization, validation and change, so later participants can reconstruct not only what exists but why it exists and what evidence supports it.

## Principles

1. **Useful knowledge:** preserve information that materially supports later understanding, decisions, implementation, validation, maintenance or revision.
2. **Continuity:** keep material relationships between intent, context, decisions, behavior, realizations and evidence intelligible.
3. **Sufficient structure:** use the smallest meaningful artifact; expand when real semantic pressure exposes a distinction necessary to preserve.
4. **Clear responsibility:** preserve distinct meanings of Support Notes, Documents, Nexus and Continuity Paths; do not duplicate another artifact's explanatory or connective authority.

This is not a required inventory of documents or sections. Docs Standard owns documentary structures and meaning; Method coordinates use; Tooling materializes supported semantics.
