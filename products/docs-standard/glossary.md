# Docs Standard — conceptual glossary

**Owner:** VSlices Docs Standard. **Status:** non-artifact concepts migrated; older type and level claims qualified.

| Concept | Meaning |
| --- | --- |
| Living documentation | Preserved knowledge that can evolve with understanding, decisions, realizations, validation and change. It does not imply every historical artifact must be continuously rewritten. |
| Knowledge artifact | A preserved unit of knowledge useful to future work; a descriptive umbrella, not a new normative catch-all family. |
| Documentary boundary | Distinction between the knowledge or continuity one artifact preserves and responsibilities belonging elsewhere. |
| Reference | An explicit pointer to another artifact, concept, decision, observation or realization. |
| Documentary relation | A meaningful link allowing knowledge to remain connected and reconstructible. |
| Traceability | The ability to follow relevant connections through discovery, decisions, realization, validation and evolution; not necessarily a formal exhaustive matrix. |
| Useful knowledge | Knowledge that supports future understanding, decision, implementation, validation, maintenance or revision. |
| Preserved intent | Meaning, purpose, reasoning and restrictions that remain understandable after the original discussion. |
| Documentation drift | Divergence between preserved description and evolving knowledge, decisions, behavior or implementation. |
| Outdated knowledge | Information no longer supported by the current state of evidence or decisions. |
| Documentation debt | Missing, disconnected or obsolete knowledge that materially impedes later work. |
| Documentary affinity | Contextual usefulness of an artifact perspective, not a compulsory document-to-phase assignment. |

## Historical language not promoted

- **Document type and structure:** old template/section descriptions must not override current root-question definitions and progressive semantic-pressure branches.
- **Document maturity/stage:** do not reinstate the old L0–L3 ladder as an intrinsic property or required progression.
- **Artifact family:** current compact meanings are Support Note = specific detail; Document = one large question; Nexus = set of large questions; Continuity Path = map of question-bearing routes preserving topical continuity.

The specific current questions are recorded in [root-question inventory](root-question-inventory.md). Current machine-consumable definitions remain in [vslices/docs-standard](https://github.com/vslices/docs-standard).
