# Project source documents

## Status

Historical/transitional source material preserved from the VSlices Development project context.

These files were copied here verbatim so the project-level source attachments can be retired without losing information that may still need to be promoted into canonical VSlices definitions.

They are **not canonical definitions merely because they live in this repository**.

Current canonical or candidate definitions should live in the appropriate suite or product surface outside this directory.

## Purpose

Use these files to:

- recover wording or distinctions that have not yet been promoted;
- compare older snapshots with current definitions;
- reconstruct why a concept changed;
- identify knowledge that still needs a canonical owner;
- migrate useful material into foundations, mechanisms, products, relationships, lifecycle, forces, public documentation, Tooling, VSIR, Framework, or another owning surface.

Do not update these files to make them look current.

If a concept evolves, update its canonical definition and preserve these files as historical evidence.

## Migration rule

```text
historical source
    -> inspect
    -> identify still-useful knowledge
    -> determine semantic authority
    -> promote to canonical owner
    -> preserve this source unchanged as evidence
```

The objective is eventually to make normal VSlices reconstruction independent from these snapshots while retaining them for provenance.
